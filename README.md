# RZXCore

Shared core library plugin for the RZX plugin network.

## Features

- **SQLite Database Support**: Integrated database utility for local storage.
- **Item Builder Utilities**: Easily construct and customize Bukkit item stacks.
- **Plugin Integration Hooks**: Out-of-the-box support for Vault and PlaceholderAPI.

## Development

Built using:
- Java 25
- Maven (see [pom.xml](pom.xml))
- Paper API (1.21.1)
